# Decision log

Append a new entry at the bottom of docs/decisions.md. Never rewrite old entries. If a choice changes, add a new entry and set the old one's Status to superseded.

Format:

## YYYY-MM-DD Short title
Chose: what was picked.
Why: the reasons, in plain words.
Alternatives: what else was considered.
Cost: money, time or risk.
Revisit when: the trigger that should reopen the choice.
Status: open | confirmed | superseded

Write plain, short sentences. Explain jargon the first time it appears. No dashes in sentences.
